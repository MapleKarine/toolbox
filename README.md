# Toolbox

Tools for conlanging

- [Gloss](https://maplekarine.github.io/toolbox/gloss) — Format neatly aligned interlinear glosses.
- [IPA Chart](https://maplekarine.github.io/toolbox/ipa_chart) — Automatically generate consonant tables and vowel charts from a list of IPA phonemes.
- [Unicode Analyzer](https://maplekarine.github.io/toolbox/unicode_analyzer) — Insert text and inspect the Unicode characters.
